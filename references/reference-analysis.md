# 看原片时留下什么

## 素材与证据

- URL通过egolite正常访问，读取真实文案、可点击话题、官方活动线索、合集与作者声明。正常可取得的媒体保存到本项目；不越过私密、付费、登录验证或创作者限制。访问不通说明具体失败步骤，继续能做的工作；登录或扫码按浏览器技能交接同一空间。
- 本地文件先 `media.py inspect`，核对视频和音频各自时长、start_time、尺寸与帧率。源片、代理片和独立音频可能不同长，不能看文件名猜时间轴。
- 校对过的参考分析可复用，但核对源文件/URL，重看必要片段。用户要求新片从零做时，不沿用旧主题的文案、表演和稀疏模板；原参考的真实观察可以复用。
- `rea-video` 可用时按其技能取得分析并看图纠正；工具输出只是候选。缺少命令时用 FFmpeg 取帧和 Codex 观察，不为此自动装完整外部项目。

## 观察的层次

| 要看 | 有用记录 | 不足记录 |
|---|---|---|
| 叙事 | 人要回家，门即将关闭，文书改变通行结果 | 有个小人 |
| 构图 | 前景守卫、中景门、远景街道建立障碍，左上留给说明 | 黑底、好看 |
| 动作 | 敲鼓次数推进关门时刻；递文书后守卫改变动作 | 人物出现、字幕淡入 |
| 深度 | 一般规则后给例外，再用材料或案例追问 | 介绍规则 |
| 声音 | 鼓声落在击槌，配乐跨转场；具体来源尚未确认 | 141个音效全部同步 |

每个单元记录时码、来源类型与置信度、首中尾、事件、文字、空间与声音落点，用实际帧支持。有变化的单元查看连续帧，不凭单图断言2D/3D/AI/实拍。软件、字体名、音乐曲名不确定就标未知。检测信号不能变成确定结论。

## 分开可迁移与本片独有

可迁移：问题怎样提出；主体道具怎样贯穿；规则、实例、例外、后果怎样排列；文字层级、空间、解释性停顿、音乐连续性。

本片独有：朝代、公职、角色身份、数字、台词、地图、镜头总数、片长和原混音。它们不是下一条的默认参数。

## 参考HTML

`reference/analysis.json` 按数据约定保存。HTML回答“做了什么、为什么有效、新题怎么借鉴”，带真实时码和实际帧。本地媒体可播放则支持定位；只有网页时提供来源链接和真实截图，不放打不开的远程MP4假播放器。

声音未知、人声未听审、镜头归类存疑保留在报告里。新话题另查事实；参考片制作优秀不代表其历史或科学断言已经核验。
