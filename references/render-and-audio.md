# 引擎与声音

## 工程

`project.py init` 提供主题无关的Canvas/FFmpeg运行时。实现 `production/film.mjs` 的 `renderFrame({canvas,ctx,time,frame,project,episode,facts})`；可在模块加载时准备资源和缓存，每帧确定性画当前状态。运行时清理上下文，逻辑连续性由场景时间推导。

初始film只抛出“尚未编写”，不会产出数字卡冒充成片。构图、环境、角色、道具、景别、文字由Codex针对参考新写。实拍、录屏、素材剪辑或3D可用其他引擎，仍交付统一时码和可验证MP4。

依赖只安装在项目，不把node_modules或视频塞进技能目录。默认2个工作进程、各2个编码线程，按设备调整；`.render/progress.json` 保存进度，运行日志按配置存放。不要因任务尚在运行就重复启动同一批渲染。

fps支持 `30000/1001` 等分数；先用总帧数锁片长，再对齐章节。所有片段尺寸、帧率、像素格式和时基一致。需要保持参考全长声音时核对真实音频及帧边界，不写死7分06秒。runtime拒绝靠 `-shortest` 悄悄截断影片。

`project.fonts` 配置可用字体路径与族名。检查中英数字混排、缺字、遮挡和实际导出字形；“甲202”不能交给只有拉丁字的数字字体。字号按当前参考与输出尺寸设计，34不是固定值。

## 音轨模式

| mode | 用途 | 验证 |
|---|---|---|
| copy-full | 明确采用适合本片的同一整轨，长度匹配 | 单次音频流拷贝，无循环裁拼；PCM及样本数一致 |
| prepared | 本次已制作好的旁白/BGM/音效全长混音 | 覆盖全片、接缝首尾、响度及人声关系；不要求与原混音一致 |
| none | 用户要求静音或参考/题材确实无声 | 记录理由，不默认把有声参考改成无声 |

未决定就保持mode未设置，不能导出静音片宣布完成。不能保留原片无关旁白；拥有的是混音就不叫纯BGM。分离要检查残留，无法满足则解决具体素材缺口或说明实际替代。新旁白用新稿和已授权普通音色，“像参考”不自动要求克隆真人。

循环音乐要在乐句边界制作并检查尾音和连续性，不在每章重启或插无声。效果音跟着新事件，不把原片低置信候选时间点直接复制。

## 输出预览

通常为H.264/yuv420p MP4与AAC，尺寸和帧率服从用户与参考。竖版从构图开始设计，不硬裁横版。

项目 `scripts/serve.mjs` 绑定127.0.0.1、支持Range、不自动打开浏览器。需跨轮持续访问时独立托管并复查；macOS可用专属launchctl服务，不借用或重启其他项目服务。不需要在线预览时交付本地HTML与MP4即可。

检测输出仅是数值证据和候选；零静止候选不能证明精彩。
